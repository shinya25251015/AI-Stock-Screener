# 電業社機械製作所(6365)・いであ(9768) の特別損益チェックと①一次確認（2026-08-20）

骨太2026×海底レアアースの連想パスで発火前かつ主軸サイズ帯に入った2社を、
新しい判定順（**特別損益チェック → ①一次確認**）で潰した。

**結論: 6365は①不成立で見送り。9768は①が部分的に成立するが受注が減っており観察継続。**

## 1. 電業社機械製作所(6365) — 数字はクリーン、しかし①不成立

**原本＝2026年３月期 決算短信〔日本基準〕（連結）2026-05-15開示**（全21ページ）
および **2027年３月期 第１四半期決算短信 2026-08-07開示**（全10ページ）。いずれもPDF全文を取得・精読。

### 1-1. 特別損益チェック＝**陰性（一過性の嵩上げなし）**

連結損益計算書の原本（単位:百万円）:

```
              前期      当期
経常利益              3,400    3,640
税金等調整前当期純利益   3,400    3,640   ← 経常＝税前で完全一致
法人税等合計            974     1,025
当期純利益            2,426    2,615
```

**経常利益と税金等調整前当期純利益が2期とも同額**＝特別利益・特別損失ともにゼロ。
「特別利益」「特別損失」「投資有価証券売却益」の語も全21ページで**0件**。

→ **実績ROE8.9%（原本記載の自己資本当期純利益率。Yahoo値8.94%と一致）は素の収益力で、
正常化は不要。** 大同信号(6743)・日本カーボン(5302)とは異なり、**クリーンな確認が取れた
最初の銘柄**。`verified_fundamentals` に `special_items_checked: true` を書ける状態。

実効税率は 1,025 ÷ 3,640 ＝ **28.2%**（原本から算出）。

### 1-2. ①テーマ言明＝**不成立**

**全21ページで「海洋」0件・「海底」0件・「深海」0件・「レアアース」0件・「南鳥島」0件。**
出現するのは「資源」1件（経営資源の意味）・「水処理」1件・「水力」2件・「中期経営計画」1件のみ。

「今後の見通し」の記載も**マクロ環境と業績予想の数字だけ**で、成長戦略・新規事業・
next-generation の言明が一切ない:

> 今後の見通しにつきましては、雇用・所得環境の改善や堅調な企業収益を背景に、景気は緩やかな
> 回復基調が継続することが期待されるものの、米国による関税政策の動向や…先行き不透明な状況が
> 継続するものと予想されます。…当社グループの受注については、受注高27,000百万円を目指します。

→ **「深海揚泥ポンプだから南鳥島の海底レアアースに効く」というのは、こちらの連想であって
会社の原本には一切根拠がない。** santecの「CPO本命」、東洋電機製造の「GX電力」、
YE DIGITALの「スマート農業」とまったく同じ型で、**§8により不採用**。

### 1-3. 事業の質は本物（記録として残す）

- 26/3期: 売上28,189百万(+0.4%)・営業3,495百万(+8.0%)・**営業利益率12.4%**・純利2,615百万(+7.8%)
- **自己資本比率73.5%**、**有利子負債ゼロ**（インタレスト・カバレッジ・レシオが「-」＝利払いなし）
- 27/3期1Q（2026-08-07）は売上5,827百万(+9.0%)・営業730百万(**+200.4%**)と絶好調
- **ただし通期予想は営業3,100百万＝-11.3%の減益**（据え置き）。予想ROEは
  2,550 ÷ 30,658 ＝ **約8.3%** で品質フロア6%は超える（大同信号のようなフロア割れ懸念はない）
- 受注高26,963百万(+0.8%)だが**受注残高27,293百万＝-4.3%**

### 1-4. 判定

**見送り。東洋電機製造(6505)とまったく同じ枠**——「安さ（比0.67）と品質（自己資本比率73.5%・
無借金・営業利益率12.4%）は本物だが、2035テーマとの固有の接続を会社が語っていない」。
本プロジェクトは§8で運営されており、**言明の無い安さは「安いなりの理由がある」と扱う**。

再評価の条件: 海洋開発・海洋資源・深海関連の受注または方針が**原本に明記される**こと。
それが出ない限り、安さだけで昇格させない。

## 2. いであ(9768) — ①は部分的に成立。ただし受注は減っている

**原本＝2026年12月期 第２四半期（中間期）決算短信〔日本基準〕(連結) 2026-08-03開示**
（TDnet `140120260731505012.pdf` 全12ページを取得・精読）。**12月期決算**。

### 2-1. ①テーマ言明＝**部分的に成立**（電業社と決定的に違う点）

原本に**海洋無人機の実業が明記されている**:

> 売上高は**大規模な海洋環境調査、ＡＵＶ設計製作・運用支援業務**、化学物質の環境リスク評価業務、
> 土壌調査関連業務等の売上が増加したことにより、同５億４千８百万円増加の128億７千６百万円（同4.4％増）

**AUV（自律型無人潜水機）の設計製作・運用支援**は、骨太2026の成長戦略が名指しする
「**海洋無人機（海洋ドローン）**」「**海洋状況把握（ＭＤＡ）**」そのもの。
環境コンサルタント事業は売上88.78億(+9.3%)・セグメント利益15.41億(**+20.1%**)と伸びている。

さらに **2025-09-26にブルーイノベーション(5597)と資本業務提携**し、同社の第三者割当増資を
80,900株・@2,472円（約2億円）で引き受けている。協業領域は
**「公共インフラのドローン点検ソリューションの共同開発・提供」「BEPポートによる遠隔点検・監視」
「水域・空域・陸域を統合した自動点検システムの共同開発」**（※これは準一次＝報道ベース。
適時開示原本はTDnetの保存期間を過ぎており未取得）。

→ **「水中AUV × 空のドローン × 陸を統合したインフラ自動点検」という筋は実在する。**
⑥老朽化更新（インフラ点検）とも、骨太2026の海洋分野とも接続する。

### 2-2. しかし「拡大言明」としては弱く、②は逆方向

- **第6次中期経営計画（2025年から3か年）のスローガンは「ＤＸ推進と共創による新たな価値創造に
  向けた変革への挑戦」**で、5つの戦略（事業・DX・人財・投資・サステナビリティ）はいずれも
  一般的な経営方針。**海洋資源・レアアース・南鳥島への言及は原本にゼロ。**
- **受注高は前年同期比 -4.2%（135億15百万）**。しかも原本は減少要因として
  「**ＡＵＶ設計製作・運用支援業務**、防災・減災関連業務、インフラ施設の設計・維持管理関連業務等の
  受注が減少」と明記——**①の中核であるAUVの受注そのものが減っている。**
- 受注残高も -2.4%（150億38百万）。
- → **売上では伸びたが受注では減った**。②（独立した定量の裏付け）は**反対方向**に出ている。

### 2-3. 数字

- 中間期: 売上12,876百万(+4.4%)・営業2,217百万(+8.5%)・経常2,303百万(+7.6%)・純利1,561百万(+7.5%)
- **自己資本比率81.4%**、BPS4,412.07円（Yahoo値と完全一致）、営業利益率**17.2%**
- 通期予想: 売上25,700(+4.4%)・営業3,400(+6.7%)・**純利2,400(+0.8%)**。
  予想ROE ＝ 2,400 ÷ 31,497 ＝ **約7.6%** で品質フロアは超えるが余裕は薄い
- 安さ: PBR0.85／実績ROE8.01% → 妥当PBR1.00倍 → **比0.85＝発火前**。時価総額280億＝**主軸サイズ帯**

### 2-4. 特別損益チェック＝**未完了**

2Q短信には特別利益・特別損失の計上なし（0件）。ただし**実績ROE8.01%の期＝25/12期本決算
（2026-02-09開示）の原本は未取得**（TDnetの保存期間を過ぎている）。
実績8.01%と会社予想7.6%が近いことから大きな一過性は無さそうだが、**確証はない**。
→ Yahoo!ファイナンスの開示ミラーか有価証券報告書（2026-03-26提出・第58期）で要確認。

### 2-5. 判定

**観察継続。①は準一次で成立寄りだが、②が反対方向（受注減）に出ているため昇格させない。**
再浮上の条件は、(a)AUV・インフラ自動点検の**受注高がプラスに転じる**こと、または
(b)中計・適時開示で**海洋資源・海洋開発への拡大が原本に明記される**こと。
