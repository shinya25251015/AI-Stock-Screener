## 0. 先に読むべき業種固有の注意

**製錬は市況（銅・亜鉛・ニッケル・金）に業績が直結する典型的なシクリカル。**
実績ROEは金属価格のピークで大きく膨らむため、**名村造船所を「造船好況のピーク」で
却下したのとまったく同じ罠がある**。今回も会社予想ROEで引き直すと順位が激しく入れ替わった。

さらに **17社すべて特別損益チェックが未実施**（2026-08-18に新設した手順）。
製錬所は巨額の設備を持つため減損・操業トラブルの特別損失も、資産・政策保有株の
売却益も出やすく、**歪みは両方向に効く**。下記はいずれも確定ではない。

## 3. §8で検知した2件（今回もガードが効いた）

### 3-1. 「アサヒホールディングス(5857)」は**コードが正しく、社名が古かった**

**2023年7月1日付で「AREホールディングス」へ商号変更**。ARE は Asahi / Resources /
Environment の頭文字で、事業内容を社名に盛り込むのが目的。1952年に朝日化学研究所として
創業し、写真定着液から銀を回収する事業が祖業、2009年に持株会社が上場。
→ **クラフティア（旧九電工）に続き2件目の「社名が古い」型**。

## 4. 東邦亜鉛(5707)の「比0.23」を信じてはいけない

実績ROE**40.37%**は他16社（1.96〜24.55%）から突出しており、**製錬本業の収益力とは
考えにくい**。この水準が出る典型は (a)一過性の特別利益、(b)自己資本が大きく毀損していて
分母が小さい、のいずれか。**どちらであっても比0.23は実態を表さない。**
会社予想で引き直した0.83のほうが実態に近いが、それも確定ではない。

→ **この銘柄は「安いから買う」ではなく「なぜ40%なのか」を原本で潰すのが先。**
決算短信原本で(1)特別損益、(2)自己資本の推移、(3)増資・資本政策の有無を確認する。
時価総額210億は主軸サイズ帯のど真ん中なので、潰す価値はある。

## 6. この軸の位置づけ（暫定）

発火前が17社中7社は**⑥老朽化更新（35社中12社）に次ぐ産出**で、成長継続軸（9社中0）とは
明確に違う。ただし⑥と違って**床がコモディティ市況**であり、
「安定したコア事業（床）の上に未評価の次世代テーマが乗っている」という
本プロジェクトのテーゼ（床＋オプション型）とは**質が異なる**。
名村造船所を却下した理由「床が景気敏感＝thesis不適合」がそのまま当てはまりうる。

→ **2035テーマ（重要鉱物の国内供給網・EV電池材料・半導体向け高純度金属）が
個社の言明として原本にあるか**を、①で厳しく見る必要がある。
